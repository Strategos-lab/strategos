# Self-hosted fonts

Both fonts are bundled from the repository (no CDN, no external requests) and precached by the
service worker, so they work offline. Latin subset, variable weight axis only.

| File | Font | Version / source | License |
| --- | --- | --- | --- |
| `inter-latin-wght-normal.woff2` (47 KB) | Inter (variable, wght 100–900) | `@fontsource-variable/inter` 5.3.0 | SIL OFL 1.1 — `OFL-Inter.txt` |
| `jetbrains-mono-latin-wght-normal.woff2` (39 KB) | JetBrains Mono (variable, wght 100–800) | `@fontsource-variable/jetbrains-mono` 5.3.0 | SIL OFL 1.1 — `OFL-JetBrainsMono.txt` |

The license texts are also published with the app at `licenses/OFL-*.txt`.
